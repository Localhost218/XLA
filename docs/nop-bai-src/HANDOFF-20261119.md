## Việc còn lại theo thứ tự

1. Đọc `slide-v3\STATUS.md` → dựng nốt slide v3 (≤ 30), render từng slide và tự xem, kiểm font + grep từ cấm, xuất PDF nhúng font.
2. Up pptx + pdf lên Drive làm bản mới của hai file ID; kiểm sha256 bằng `page.context().request.get('https://drive.google.com/uc?export=download&id=<id>')`.
   Bẫy: tab Drive nằm sau tab khác thì trang ngừng vẽ → `page.bringToFront()`; menu tự đóng giữa các lệnh → gộp More actions → File information → Manage versions → Upload new version trong MỘT lần run_code; `browser_file_upload` bị Chrome chặn → server `py -3.13 -m http.server` bind 127.0.0.1 chỉ chứa đúng file, fetch trong Node, gắn File qua DataTransfer, tắt server ngay.
3. Khớp transcript: thêm khối `slides: [{number, title (đúng chữ trên slide), sections: [...]}, …]` vào `transcript\transcript.yaml`, điền số "cùng khung N hộp" theo slide mới, chạy build (kiểm số slide ≤ 30, tiêu đề, từ cấm).
4. Hỏi người dùng có merge XLA PR #6 không.
